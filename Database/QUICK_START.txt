🚀 CÁC BƯỚC THỰC HIỆN NHANH:

1️⃣  Mở SQL Server Management Studio (SSMS)

2️⃣  Chạy file: 01_CreateTables.sql
    → Tạo database mới và cấu trúc bảng
    → ⚠️ Sẽ XÓA database cũ nếu có!

3️⃣  Chạy file: 02_InsertData.sql
    → Thêm dữ liệu mẫu với GUID cố định

4️⃣  Kiểm tra file ảnh trong folder:
    D:\Website_Cosmetics\Website_Cosmetics\Website_Cosmetics\wwwroot\public\images\products\
    
    Cần có 3 file:
    ✅ cay-son-superstay-135.jpg
    ✅ nguoi-mau-superstay-135.jpg
    ✅ moi-mau-superstay-135.jpg

5️⃣  Khởi động website:
    cd D:\Website_Cosmetics\Website_Cosmetics\Website_Cosmetics
    dotnet run

6️⃣  Test Virtual Try-On:
    URL: http://localhost:5210/Products/Details/7ADE93DF-3D89-47FA-B490-58C6CA4C2706
    Click nút "Virtual Try-On"
